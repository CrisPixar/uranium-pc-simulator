# Uranium PC Simulator

Мод игры **Blue PC Simulator v1.9.1.11** (Unity 2021.3.45f1, IL2CPP).

| | |
|---|---|
| Название | Uranium PC Simulator |
| Пакет | `com.UraniumPCS.UraniumPCSimulator` |
| Иконка | не изменена (как в оригинале) |
| Разрешения | не изменены (как в оригинале) |

## История версий

### v3 (по фидбеку)
- **Заголовок меню больше не «мигает»**: игра через 1–2 секунды перезаписывала
  заголовок рантайм-литералом из `global-metadata.dat`. Литерал заменён
  in-place (той же длины): `<color=cyan>Uranium</color> <color=red>PC</color> Simulator`
  (`mod/patch_metadata.py`).
- **Принтеры 512/1024 и горизонтальный баннер видны в Маркете**: у новых ShopItem
  было `bitcoin=5` — карточки с BTC-ценой, не купленные ни разу, рендерились как
  неинициализированный плейсхолдер «Title», с которым ничего нельзя сделать.
  Теперь `bitcoin=0` — `ShopItem.IsUnlocked()` сразу возвращает true, карточки
  отображаются и покупаются (`mod/patch_bundle_v3.py`).
- **Горизонтальный баннер заказывается на сайте PrintExpert** (в браузере, где
  первый баннер): загружаете **широкую картинку 70×32** — приезжает
  горизонтальный баннер; **32×70** — вертикальный, как раньше. Реализовано
  патчем `PrintExpert.Purchase` (arm64+arm32): проверка размера принимает оба
  формата, префаб выбирается по пропорциям (поле alertText переназначено на
  TextureLoader префаба BannerStand_H).
- **Исправлен двойной спавн баннера** при покупке на сайте: раньше игра
  инстанцировала копию префаба, отдавала её в InstantDelivery (который создавал
  ВТОРУЮ, белую копию) и текстурировала первую. Теперь InstantDelivery создаёт
  единственную копию, и текстура применяется к ней.
- **Сообщения сайта**: «неверный размер» выводится через Main.FadeText.
- **В песочнице все покупки бесплатны**: монеты не списываются (штатная ветка
  Main.Spend при sandbox + обход проверки денег на сайте), **BTC-разблокировки
  не списывают BTC** (в sandbox цена считается 0, кошелёк не меняется — патч
  ShopUI.ButtonDown). Вне песочницы всё как в оригинале.
- **Чёрная сетка между пикселями и RGB-субпиксели** (красный/зелёный/синий на
  голограммах вблизи): near-текстура `rgb` материала Merge_DistanceMask
  переведена в белую RGBA32 (вместе с уже белой Grid/far-текстурой это убирает
  и сетку, и субпиксели).
- **Релизы**: каждая сборка получает **свой тег** `v1.9.1.11-uranium.b<N>`
  (старые релизы не перезаписываются).

### v2 (исправление краша)
- **Исправлен краш при входе в сохранение**: в v1 сериализация клонов случайно
  перезаписывала исходные префабы принтера и баннера (UnityPy save_typetree
  мутирует объект-источник). Теперь клоны сериализуются без изменения источников
  (см. `mod/patch_bundle.py`), а `mod/verify_bundle.py` сверяет бандл с
  оригиналом объект-в-объект.
- Заголовок главного меню: **Uranium PC Simulator** (было Blue PC Simulator).
- Убрана надпись «(5BTC)» у режима песочницы (он бесплатен).
- Полный набор проверок: `mod/verify_bundle.py` (A–H) + проверка хэшей в CI.

## Что изменено

1. **Имя игры и пакет** — приложение называется «Uranium PC Simulator», пакет `com.UraniumPCS.UraniumPCSimulator` (иконка и разрешения не тронуты).
2. **Принтеры Apson A3 512×512 (15 000 монет) и 1024×1024 (30 000 монет)** — новые товары в Маркете, разблокировка как у остального (5 BTC).
3. **Горизонтальный баннер** — новый товар в Маркете (100 монет). На него можно **бросить распечатанную картинку** — она повесится на полотно (компонент PaperFrame, как у рамок для картин). Вертикальные баннеры у PrintExpert не тронуты.
4. **Нормальная физика** — SolverIterations 6→10, VelocityIterations 1→4, BounceThreshold 2→1, SleepThreshold 0.005→0.003 (гравитация -9.81 не тронута).
5. **Термодинамика/кондиционер** — компьютеры остывают до температуры кондиционера **в 2 раза быстрее**; вместо снега кондиционер испускает **радужную гирлянду** (мерцающие огоньки всех цветов, материал ParticleFlare).
6. **Убрана чёрная сетка LCD-экранов** — текстура Grid переведена в полностью белую RGBA32 (шейдер Merge при белой сетке не изменяет картинку).
7. **Песочница бесплатна** — переключатель Sandbox больше не требует и не списывает 5 BTC.
8. **Без искажения цветов при печати** — печать использует нужное количество краски по каждому каналу CMYK вместо обрезания по остатку.
9. **Краски в 3 раза больше** — один картридж = 3 заправки (Printer..ctor: totalInk/remainingInk 1.0 → 3.0, патч и arm64, и arm32).
10. **Paint: максимальный холст 1024×1024** (было 256×256).
11. **Уровни красок в ПК** — уже есть в игре: в диалоге печати кнопка **Supply** показывает 4 индикатора CMYK.

## Сборка (GitHub Actions)

Пуш в `main` (или Manual run) запускает workflow `.github/workflows/build.yml`:
apktool b → проверка содержимого (хэши + сигнатуры v3) → zipalign → apksigner
→ артефакт + релиз. **Каждая сборка — новый тег** `v1.9.1.11-uranium.b<N>`
(N растёт с каждым прогоном), старые релизы остаются.

Готовый APK: **Releases → последний тег → UraniumPCSimulator.apk**.

Подпись: `uranium.jks` (alias `uranium`, пароль `***REMOVED-KEYSTORE-PASS***`) — лежит в репозитории,
чтобы все сборки подписывались одинаково и ставились поверх друг друга.

## Как сделано (правки)

- `mod/patch_so_v3.py` — нативные патчи v3 (arm64+arm32, код-кейвы в нулевом
  паддинге .text): бесплатный BTC в песочнице (ShopUI.ButtonDown → кейв:
  цена 0 при Main.sandbox), обход проверки денег на сайте (обёртка get_Money),
  приём картинок 32×70 и 70×32, выбор префаба баннера по пропорциям, спавн
  одной копии (фикс двойного баннера), Main.FadeText для неверного размера.
- `mod/patch_metadata.py` — in-place замена рантайм-литерала заголовка в
  `global-metadata.dat` (строка той же длины, длины хранятся в индекс-таблице).
- `mod/patch_bundle_v3.py` — данные v3: bitcoin=0 у новых ShopItem, текстура
  `rgb` → белая RGBA32, PrintExpert.alertText → TextureLoader (BannerStand_H).
- `mod/verify_v3.py` — полная проверка v3 (байты патчей + семантика ветвлений
  + данные бандла + метаданные + инварианты v2).
- `mod/patch_so.py` — патчи v2 `libil2cpp.so` (arm64-v8a + armeabi-v7a):
  песочница (SceneSettings.SetSandbox: сравнение цены с 0 / отмена списания),
  краски ×3 (Printer..ctor), точная печать (Printer.PrintAvailableArea: клампы →
  needed), охлаждение ×2 (CPU.FixedUpdate: -10 → -5).
- `mod/patch_bundle.py` — правки `assets/bin/Data/data.unity3d` (UnityPy):
  Grid → белая, Paint 1024, PhysicsManager, productName, гирлянды в
  level1/3/4/5/6, клоны префабов принтеров 512/1024 и горизонтального баннера
  (+PaperFrame), новые ShopItem'ы, регистрация в Market, строка локализации
  «Horizontal Banner».
- `AndroidManifest.xml` — пакет `com.UraniumPCS.UraniumPCSimulator`.
- `res/values/strings.xml` — `app_name` = Uranium PC Simulator.

Исходное APK: Blue PC Simulator v1.9.1.11 (декомпиляция с разрешения создателя мода).

## Установка

Снести оригинал (другая подпись и другой пакет — впрочем, пакет другой, так что
можно ставить рядом), с-enable «Установка из неизвестных источников», поставить
`UraniumPCSimulator.apk`.
